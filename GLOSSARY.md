# Glossary

Canonical domain terms for Podcast Trust Report. Use these exact terms in code, types, UI copy, and docs.

- **Podcast** — The show or channel that publishes episodes.
- **Episode** — A single YouTube podcast video being analyzed. (*Avoid:* video, show)
- **Transcript** — The timestamped text produced from an Episode.
- **Trust Report** — The interactive OpenUI output generated for an Episode (summary, chapters, fact-checked claims, and separate Host and Guest trustworthiness assessments).
- **Chapter** — A timestamped topic segment of an Episode.
- **Claim** — A factual assertion made in an Episode that is evaluated for accuracy in the Trust Report.
- **Host** — The regular presenter or interviewer of a Podcast.
- **Guest** — An invited speaker on an Episode.
- **Trustworthiness** — The canonical measure of reliability for an Episode, Host, or Guest (e.g., `Trustworthiness Score`, `Host Trustworthiness`, `Guest Trustworthiness`). (*Avoid:* credibility)
- **AI Connection** — A named, locally stored configuration for an AI provider (provider type, model ID, provider-specific credentials or URL, and connection-level **Tools** such as Web Search). Multiple AI Connections can be saved, with one active at a time.
- **Settings** — User configuration stored locally in the browser, organized into groups such as **Personal Settings** (e.g., app theme) and **AI Settings** (**General** such as proxy configuration, and **Connections** for managing **AI Connections** and their tools).
